# Contributing

agentcad is developed test-first (TDD): write a failing test, then the code.

1. Environment: Python >= 3.12 and `python -m pip install -e .` (numpy, scipy, trimesh, manifold3d, python-fcl, matplotlib, pillow).
2. Tests: `python -m unittest discover -s tests -t .` (full, ~3 minutes) or `AGENTCAD_RAPIDAS=1 python -m unittest discover -s tests -t .` (skips the heavy ones, ~1 min). pytest is not required.
   CI runs the quick suite on Python 3.12 and 3.13 for every push and PR, and the full suite on `main`.
3. New block: `agentcad nuevo_bloque <name>` creates the manifest, a draft skeleton and a failing contract test. A block without a test is not registered.
4. Core principle: **digital results are never labelled as physical.** A tool without a validated model returns `no_validado` / `no_evaluable`, not a number. Every new output carries `nivel_validacion: "digital"` and its limits.
5. Determinism: same inputs, same outputs. No unseeded randomness and no clock dependence in results. Tests that compare stored floats must use a tolerance (see `casi_igual` in `tests/test_laminador.py`).
6. Language: the API surface (block names, JSON field names, messages, `agentcad.toml` keys) is Spanish and is kept stable; do not rename identifiers. Documentation is English first (`README.md`) with a Spanish mirror (`README.es.md`).
7. Do not commit user data: `registro/`, `trabajo/`, caches, tool binaries or credentials (see `.gitignore`).
8. The README demo GIF is generated by `python docs/media/demo.py`; if you change the example output it shows, regenerate it.
